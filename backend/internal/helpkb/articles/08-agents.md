# 聊天模式、导演模式、Marketer、无限画布与 Skill

## 聊天模式（/studio/agents）
1. 在输入框说出想法（要什么图片、视频或配音），可以点「添加素材」附上参考。
2. 输入 / 可以选择 Skill 库里的 Skill，让 AI 按固定做法完成。
3. AI 会帮你挑工具、写提示词并发起生成，生成同样按次扣积分。
4. 左侧保留历史对话，可以点「新对话」重新开始。

## 导演模式（/studio/director）
1. 在输入框说说你想拍什么：产品、故事、风格、给谁看。也可以从「快速开始」选一个模板。
2. AI 导演先写剧本、拆分镜，你可以逐个镜头修改。
3. 确认后逐个镜头生成，最后合成完整视频。
4. 做过的项目都在「导演项目」里，可以随时回来继续。

## Marketer（/studio/marketer）
AI 营销专员。从「热门玩法」直接开始，或在「专家市场」选一位专家（每位自带一套工作方法和技能组合），把营销任务交给 TA，例如写广告文案、做产品图和短视频。

## 无限画布（/studio/canvas）
在无限画布上串联多个步骤：分镜、批量出图、图生视频、对比不同版本。画布里的作品和 Studio 作品库共用。画布列表可以搜索，已有画布在 /studio/canvas/library。

## Skill 库（/studio/skills）
保存常用的 Skill（一套固定的做法和提示词），之后在聊天模式输入 / 调用。Skill 库为空时，先去添加几个常用的 Skill。

## 灵感与模板
- 灵感社区（/studio/inspire）：看大家的作品，喜欢的一键「做同款」。作品默认只有自己可见，只有主动发布才会公开。
- 模板（/studio/templates）：挑一个现成的创意，一键带着提示词去生成。
