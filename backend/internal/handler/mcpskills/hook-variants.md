# Hook variants

The first 2–3 seconds decide whether people keep watching. Make several versions of one ad that differ only in the opening, so the user can test them as separate ads.

## 1. Inputs and questions

- The base ad: an existing OmniMuse video, the product plus a short script, or an idea.
- How many variants? `[3 / 5]`
- Format? `[Video / Static image]`
- Language if the hook has speech or text.

## 2. Hook angles (pick different ones, never 5 versions of the same idea)

1. Question: "Still wasting RM… on …?"
2. Bold claim with a number: "3 minutes, no mess."
3. Visible problem: the pain shown, no words needed.
4. Before and after: split or quick cut.
5. Pattern interrupt: unexpected action or object in frame.
6. Social proof: "Sold 10,000 in Malaysia" (only if the user confirms it is true).
7. Direct callout: "Mums in KL, this is for you."

Write each hook as: angle, first-frame description, first spoken line or on-screen text (in the user's language). Show the list with the total price.

## 3. Generate

- Video: keep everything after the hook identical. Use the same model, references, ratio, duration and the same body of the prompt; change only the "0–3s" part and the first line of speech. Seedance 2.5 Flash is a good draft model.
- Static image: same product image and layout; change the headline and the hero visual only.
Label results "Hook A — Question", "Hook B — Bold claim" and so on.

## 4. Deliver

Show all variants side by side with their labels. Suggest running them as separate ads with the same budget for 3–5 days and keeping the one with the best 3-second view rate and CTR.
